# K.S. DEVELOPERS — Corporate Website & Kashi Hills Flagship Project

A complete, production-grade, architectural digital experience for **K.S. DEVELOPERS** featuring the flagship residential project **K S KASHI HILLS** in Enasan, Ahmedabad.

---

## 🏛️ Project Highlights

- **KASHI SIGNATURE Design System**:
  - 60–70% Warm Ivory (`#F7F5EF`) & Architectural White (`#FFFFFF`).
  - 20–30% Deep Teal (`#173F4E`, `#103440`) massing for hero & amenity sections.
  - 5–10% Champagne Gold (`#D6B56A`, `#B9984D`) accents.
- **Scroll-Driven Reveal System**: IntersectionObserver-based smooth entrance animations for typography, architectural cards, and stats.
- **Interactive 2D Blueprint & 3D Isometric Floor Plan Viewer**:
  - Block A (Type 01 & 02) & Block B (Type 01 & 02).
  - Pan, zoom, reset, fullscreen lightbox modal, and technical dimensions breakdown.
- **9-Page High-Resolution Digital Brochure Viewer**:
  - Integrated brochure flipbook with page thumbnails, zoom, and direct PDF download.
- **9 Verified Brochure Amenities**:
  - 01–09 numbered editorial rows matching Page 3 of the official brochure.
- **IS-Code Construction Specifications**:
  - Split vertical banner layout matching Page 9 of the official brochure.
- **Connectivity & Road Network**:
  - Interactive Google Maps integration + official brochure regional road network map.
- **Official Brand Assets**:
  - Hand-extracted 3D gold faceted skyscraper emblem with metallic orbital ring and latticed globe.
  - Subpixel vector typography and high-contrast dynamic contrast switching.

---

## 🚀 Tech Stack

- **Framework**: React 19 + TypeScript + Vite 8
- **Routing**: React Router DOM v7
- **Styling**: Pure Modern CSS with Design Tokens (`variables.css`, `global.css`, `components.css`)
- **Icons**: Lucide React
- **Build Tool**: Vite (Bundle size: ~103 kB gzipped)

---

## 🛠️ Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
